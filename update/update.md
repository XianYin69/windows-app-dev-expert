# update（自更新接口）

本技能本体唯一的写盘通道：变更先入 `tmp/` 镜像，比对后释放，禁止就地乱改。

## 接口

| 动作 | 语义 | 约束 |
|---|---|---|
| report | 汇总本次变更（新增／修改／删除清单） | 只写 `tmp/`，不触本体 |
| compare | 镜像与本体逐文件比对（路径、行数、链接） | 只读，输出差异 |
| release | 通过后把镜像释放到本体并删除镜像 | 须审查通过＋悬空链接为 0 |
| clean | 清理 `tmp/` 与运行产物 | 禁止触碰 `resistance/` |

## 必须

1. `resistance/` 约束文件不得删除；修改约束须先经本流程审批并记 `CHANGELOG.md`。
2. 释放前核对九项审查标准（见 [审查约束](../resistance/审查约束/审查约束.md)）。
3. 原子写：先写临时文件再替换，禁止就地截断。
4. 缓存与运行产物不得进入技能目录（一律 `tmp/` 或用户缓存目录）。

## 禁止

- 禁止跳过 compare 直接 release（静默越权）。
- 禁止跨技能写盘：只允许写本技能目录（挂接由调用方统一做）。
- 禁止用自更新规避 [注册表与服务安全约束](../resistance/注册表与服务安全约束/注册表与服务安全约束.md)。

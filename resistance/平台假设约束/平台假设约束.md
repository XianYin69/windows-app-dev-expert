# 平台假设约束（红线）

本技能服务 Windows 桌面／系统应用工程，**目标机状态一律须实测**，禁止以开发机或
「Windows 一般都有的」为默认前提。

## 必须

1. 断言「已装 Windows SDK／MSVC 工具集／VC++ 运行时／框架包」前，须给
   `scripts/sdk_probe.py`、`scripts/dotnet_probe.py` 或 `scripts/msix_probe.py` 的可复现输出。
2. 断言「证书可用」前，须区分：证书是否在 store、私钥是否可导出、是否在 HSM／智能卡、
   是否有时间戳服务——逐项来自 `scripts/sign_probe.py`。
3. 断言「API 可用」前，须给目标 Windows 构建号（`scripts/os_probe.py`）与最低版本依据。
4. 涉及企业域环境时，须说明取证是在**域机**还是**开发机**上做，两者结论不可互推。

## 禁止

- 禁止把「我的机器上有」写成「目标机上默认有」。
- 禁止假设 `signtool`／`makeappx`／`dumpbin`／`xperf`／`WinDbg` 在 PATH 中存在。
- 禁止假设 PowerShell 5.1 与 7 等价（模块、编码、语法糖差异须实测）。
- 禁止假设杀软／EDR 放行：未签名的自研工具被拦停属常见情形。
- 禁止假设长路径、LFC／ Controlled Folder Access、Defender ASR 规则为默认关闭。

## 兜底

无实测条件时：结论降级为「待取证」，标注 `[本地]`，并给出取证命令与判定阈值
（见 [降级策略](../降级策略/降级策略.md)）。

## 违规后果

误导选型与发布决策，导致在客户机／域机上安装失败、被拦停或无法复现。

# 薄技能依赖约束

本技能是**薄顾问技能**：只出可取证的 Windows 平台判据，能力一律经声明获取。

## 必须

1. 依赖只写名称、类型与来源（`dependence/dependence.md` + `deps.json`），
   每条附 `source_url` 原始链接；本地技能用 `local://<skill-id>`。
2. 跨技能协作只传「意图 + 参数」，由对方在其目录内执行。
3. 依赖缺失时记 `process_chain interrupt` 并报告缺项，禁止伪造能力继续。
4. 转派边界须显式声明：Qt → `qt-qtquick-expert`；视觉／交互 →
   `interface-design-expert`；语言级 → `cpp-expert` / `c-expert` / `python-expert`；
   通用准则 → `code-guidelines`。

## 禁止

- 禁止复制其他技能正文入本目录（含知识树细则与清单）。
- 禁止直接 import 他技能脚本或读写他技能目录。
- 禁止把转派事项自裁（例如在本技能内裁配色与排版优劣）。
- 禁止新增未声明依赖（脚本引用外部工具须先进 `deps.json`）。

## 兜底

依赖不可用时：给出「缺项 + 影响面 + 可降级判据」三段式报告，不静默跳过。

## 违规后果

能力重复且互相矛盾，技能升级时无法定位来源；越权改动他技能目录引发冲突。

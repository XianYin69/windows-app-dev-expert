# 上下文压缩机制

技能内容以「可检索的摘要」而非「大段正文」进入上下文。

## 必须

1. 每个 `.md` ≤ 50 行，只保留判据、命令与边界；解释性长文拆分或转链接。
2. 机读索引优先：叶清单与关键词以 `asset/knowledge_tree.json` 为唯一数据源，
   正文不重复罗列关键词。
3. 取证输出须压缩为「结论 + 关键行 + 命令」三段，禁止整段粘贴原始日志。
4. 参考书目只存摘要与出处，不存受版权保护的正文。
5. 跨技能只传意图与参数，不搬运对方技能正文（见薄技能依赖约束）。

## 禁止

- 禁止为省一次检索而把长文档整体内联进 `SKILL.md`。
- 禁止在清单里写无判据的形容词（「更好」「更快」须给测量命令与阈值）。
- 禁止把探针全量输出写入链或文件（截断至关键行并注明来源命令）。

## 违规后果

上下文膨胀挤占推理预算，关键判据被噪声淹没，检索命中率下降。

## 兜底

超 50 行时按主题拆分并互链，链接闭合由 `scripts/check_links.py` 复核。

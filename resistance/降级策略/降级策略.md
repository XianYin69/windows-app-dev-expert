# 降级策略（无工具链／离线时的取证降级）

Windows 探针依赖系统命令与可选工具链；缺项时按本策略降级，不得伪造结论。

## 降级阶梯

| 层级 | 条件 | 允许动作 | 标注 |
|---|---|---|---|
| L0 全量 | MSVC/SDK/dotnet/signtool/makeappx 齐备 | 实测编译、签名、打包、ETW | `[联网]`／实测 |
| L1 系统命令 | 仅 PowerShell + WMI/CIM + `sc`/`schtasks` | 环境与服务取证，不裁编译细节 | 实测（部分） |
| L2 只读 | 无管理员权限／域机受限 | 只读枚举与清单核对 | `[待实测]` |
| L3 离线静态 | 无网络且无工具链 | 只做文档级判据与清单输出 | `[本地]` |

## 必须

1. 每次取证前先跑 `scripts/os_probe.py` 与相关探针，把「缺什么」写进结论。
2. 降级结论须给**可复现的补取证命令**与判定阈值（何为通过／不通过）。
3. 探针返回码非 0 视为「未取证」，不得当作「无问题」。
4. 权限不足（`Access Denied`）与「对象不存在」必须分开报告。

## 禁止

- 禁止把 L3 静态判据写成实测结论。
- 禁止为绕过限制而建议临时关闭防护（须走企业环境约束的审批路径）。
- 禁止在缺工具链时断言「编译／签名／打包已通过」。

## 兜底

连续失败达 3 次：记 `process_chain interrupt`，输出缺项清单并求助用户或转派。

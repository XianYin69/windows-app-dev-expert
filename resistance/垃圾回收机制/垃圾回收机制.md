# 垃圾回收机制

过程工件的生命周期：生成 → 审查 → 释放 → 删除，不得长期滞留。

## 必须

1. 一切生成物先落 `tmp/` 镜像；审查通过后才释放到目标技能目录。
2. 释放后删除 `tmp/` 内对应工件与镜像目录，不留重复副本。
3. 探针运行产物（`.etl`、`.dump`、`.log`、`.msix`、构建目录）属临时物，
   一律写用户缓存目录或 `tmp/`，**禁止写入技能目录**。
4. 沙盒作业交付后删除沙盒（见 [沙盒机制](../沙盒机制/沙盒机制.md)）。
5. 回收前核对目标清单，避免把未过审内容释放出去。

## 禁止

- 禁止把缓存文件、IDE 配置、构建中间产物纳入版本库（`.gitignore` 已覆盖）。
- 禁止以「以后可能用」为由在技能目录内堆积历史副本。
- 禁止删除 `resistance/` 约束文件来「腾空间」（属破坏兜底）。

## 违规后果

技能目录膨胀且来源不可辨，审查与回滚失去依据；敏感取证数据被误发布。

## 兜底

释放失败：保留 `tmp/` 并报告冲突项，等待用户裁决，不得静默覆盖。

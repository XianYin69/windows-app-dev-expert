# 浏览器学习约束（红线）

遇不明白的 API／版本行为／系统策略，**先联网取证再作答**。

## 必须

1. 判据不明时派 `file_ops` 检索官方文档（learn.microsoft.com 优先），
   取页确证后方可引用；引用须附原始链接。
2. 取证结果写入 `references/` 时按 `[联网]`／`[本地]` 标注，二者不得混写。
3. 版本敏感结论须记录取证时的文档版本或构建号，避免后续版本漂移。
4. 网络不可用（无授权／离线）时：显式声明「未联网取证」，结论降级为 `[本地]`，
   并给出用户可自行执行的取证命令。

## 禁止

- 禁止臆造 API 名、参数、枚举值或版本行为（含把旧版行为当现行）。
- 禁止引用未取到页的 URL；禁止用搜索摘要替代原文。
- 禁止把第三方博客结论冒充官方判据（可作线索，须回官方页确证）。
- 禁止把 Qt／Web 前端问题在本技能内自答（转派，见薄技能依赖约束）。

## 兜底

连续 3 次取页失败即记 `process_chain interrupt`，转人工或改走 `[本地]` 降级路径。

## 违规后果

错误判据被下游长期复用，形成不可追溯的技术债与选型事故。

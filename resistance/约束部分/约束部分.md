# 约束部分（红线区识别规则）

本文件定义「什么算受约束的红线区」，供各节点在写盘与给建议前自查。

## 红线区判定

| 区域 | 判定条件 | 触发动作 |
|---|---|---|
| 系统不可逆 | 写 HKLM、改服务、改安全策略、卸载残留 | 须用户当轮授权＋回滚点 |
| 权限越界 | 提权、SeDebugPrivilege、以 LocalSystem 跑用户态逻辑 | 须说明必要性与最小权限替代 |
| 取证缺失 | 结论依赖未实测的 SDK／证书／策略／版本 | 降级为 `[本地]`＋给取证命令 |
| 版权与保密 | 复制他方正文、写入用户敏感路径或凭据 | 只写摘要与出处，凭据不落盘 |
| 越权写盘 | 目标不在本技能目录或 `tmp/` 镜像内 | 停止并报告，改走 update 流程 |
| 范围外领域 | Qt／Web 前端／语言级判据 | 转派，不自行裁决 |

## 判据优先级

正确性 → 安全与权限边界 → 契约完整（API／版本） → 可运维性（诊断与回滚） →
性能 → 风格。低优先级项不得推翻高优先级项。

## 写法约定

- 每条约束 ≤ 50 行、自然语言、「必须／禁止」句式，附违规后果。
- 约束变更须经 [update 审批流](../../update/update.md) 并记 `CHANGELOG.md`。

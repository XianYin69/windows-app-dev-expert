# references（知识库索引）

本目录只存**摘要与出处**，不存受版权保护的正文与缓存文件。

## 内容

- [知识树](知识树/知识树.md)：九叶 → `asset/knowledge/`（细则）＋ `asset/checklists/`（清单）
- [参考书目](参考书目/参考书目.md)：微软官方文档条目（逐条附原始链接）、源码仓库、印刷书目

## 来源标注规则

| 标注 | 含义 | 约束 |
|---|---|---|
| `[联网]` | 本技能创建时经取页确证可达 | 必须附原始链接，且链接写进 `deps.json` |
| `[本地]` | 模型既有常识，未联网确证 | **禁止附 URL**，禁止当作已验证事实引用 |

判据写法：`[级别] | 判据 | 出处`（出处为文档名或 `[本地]`），见任一
`asset/checklists/<叶>.md`。

## 版本口径

- 主口径 **Windows 11 23H2+** 与 **Windows App SDK 1.6 / WinUI 3**；
- 基线 **Windows 10 22H2**：只在叶内以「最低构建号」形式出现，不得当作新 API 依据；
- **UWP（`Windows.UI.Xaml`）为遗留口径**：只作迁移来源，不得升格为新项目建议；
- 语言层：C++/WinRT、C#/.NET 8、Rust `windows-rs`；语言级判据转 `cpp-expert` 等专项技能。

## 不可再拓扑的判据

一个候选叶只有在满足以下三条时才独立成叶：① 有独立可运行的取证手段（探针或官方页）；
② 有独立可判定的评审清单；③ 与既有叶的判据不互相蕴含。
按此判据，「通知与托盘」「安装器脚本」「符号与转储」均落在既有九叶内，
而 Qt／Web 前端／数据库须转派专项技能，故九叶为终态。

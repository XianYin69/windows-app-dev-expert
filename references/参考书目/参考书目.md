# 参考书目（出处索引）

本目录只存**摘要与出处**，不存受版权保护的正文。来源标注两类：

- `[联网]`＝本技能创建时经取页确证可达（取证 2026-10-07，HEAD 200），附原始链接。
- `[本地]`＝模型既有常识，**未经联网确证**，禁止当作已验证事实引用，禁止附 URL。

## 判据写法

`[级别] | 判据 | 出处`——出处写条目短名（如 `hidpi`）或 `[本地]`，
见任一 `asset/checklists/<叶>.md`。条目短名即上表链接内首列。

## 取证方法

```powershell
python -B scripts/knowledge_index.py --check-deps   # 每条依赖须有 source_url
python -B scripts/check_links.py --root .           # 悬空链接必须为 0
```

不可达即改标 `[本地]` 并记 `CHANGELOG.md`，禁止保留死链。

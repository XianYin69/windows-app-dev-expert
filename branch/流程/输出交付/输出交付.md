# 输出交付

## 动作

三段式交付，顺序固定：

1. **结论**：按级别排序的判据集（`[级别] | 判据 | 出处`），先 blocking。
2. **证据**：实测关键行（命令＋输出摘要），未取证项显式标 `[本地]`／`[待实测]`。
3. **命令**：用户可直接复制执行的取证与验证命令，标明所需权限与宿主 shell
   （`powershell.exe` 5.1 或 `pwsh.exe` 7）。

## 产出

- 交付正文 ＋ 勾选后的评审清单附件路径。
- 过程链：`step 输出交付 done`。

## 禁止

- 禁止把未取证的推断写成事实；禁止省略出处。
- 禁止粘贴整段日志（压缩为关键行，见
  [上下文压缩机制](../../../resistance/上下文压缩机制/上下文压缩机制.md)）。
- 禁止在交付里附带要求用户改 HKLM／系统服务却不说授权前提。

## 兜底

- 用户只要结论不要细节 → 仍附一行「取证命令」入口，便于复核。

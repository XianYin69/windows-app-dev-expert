# 初始化

## 动作

1. 确认工作目录：目标技能目录存在与否；未指定则按
   [沙盒机制](../../../resistance/沙盒机制/沙盒机制.md) 在固定路径建沙盒。
2. 挂载约束：读 [resistance](../../../resistance/resistance.md) 与
   [约束部分](../../../resistance/约束部分/约束部分.md)，确认红线区。
3. 判目标机基线：`python -B scripts/os_probe.py`（版本、构建号、架构、域、shell）。
4. 判工具链：`python -B scripts/sdk_probe.py`、`scripts/dotnet_probe.py`，
   记录缺项以决定降级层级（L0–L3）。

## 产出

- 逻辑链一条：本次作业目录、目标机基线、可用取证层级。
- 过程链：`step 初始化 done`。

## 兜底

- 探针不可运行（无 Python）→ 降 L3 静态判据，标 `[本地]`，见
  [降级策略](../../../resistance/降级策略/降级策略.md)。
- 目标目录不可写 → 报告并停在沙盒，不越权写盘。

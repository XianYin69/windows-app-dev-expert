# 流程（Process）

本目录存放本技能的执行流程细则，每个步骤独立成文件夹（文件夹名＝流程名）。

## 两条独立路径

创建（顾问）与修改是两条完全独立的流程，各自从「初始化」开始，互不交织。

### 顾问路径

```
[初始化/](初始化/初始化.md) → [问题解析/](问题解析/问题解析.md) →
[领域定位/](领域定位/领域定位.md) → [知识检索/](知识检索/知识检索.md) →
[取证探查/](取证探查/取证探查.md) → [专家判断/](专家判断/专家判断.md) →
[评审清单/](评审清单/评审清单.md) → [重构建议/](重构建议/重构建议.md) →
[输出交付/](输出交付/输出交付.md) → [收尾/](收尾/收尾.md) → 完成
```

横切节点：[浏览器学习](浏览器学习/浏览器学习.md)——遇不明 API／版本行为，
先联网取证再回到原节点。

### 修改路径

```
[初始化/](初始化/初始化.md) → [修改流程/](修改流程/修改流程.md) → 完成
```

修改路径独立运行，结束标记「完成项目修改」。

# 收尾

## 动作

1. **垃圾回收**：`tmp/` 镜像经 compare → release 释放到本体，随后删除镜像；
   运行产物（`.etl`／`.dump`／`.log`）不入技能目录（见
   [垃圾回收机制](../../../resistance/垃圾回收机制/垃圾回收机制.md)）。
2. **链落盘**：逻辑链与过程链摘要写入，未决项转 `CHANGELOG.md` 待办。
3. **自检**：`python -B scripts/check_links.py --root .`（悬空链接为 0）、
   `python -B scripts/knowledge_index.py --check-deps`、`.md` 行数 ≤ 50。
4. **git**：功能分支逐步提交 → 合 `dev` → 整体审查通过合 `main`；
   本仓无远端则**不推送**（见 [git 工作流约束](../../../resistance/git工作流约束/git工作流约束.md)）。

## 产出

- 产物清单（绝对路径）＋ 自检结果（链接／行数／依赖／探针可运行性）。
- 过程链：`完成`（顾问路径）或 `完成项目修改`（修改路径）。

## 返回机制

收尾完成＝**收口本侧对话**，结果交回调用方整合续排；调用方任务表未完成行
由其继续推进，整段任务不因本技能完成而结束。

## 兜底

自检不过 → 记 `interrupt` 回对应节点修复；重试达 10 次熔断（见惩罚机制）。

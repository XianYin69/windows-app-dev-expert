# 评审清单

## 动作

1. 取叶清单：`python -B scripts/review_checklist.py --leaf <叶id>`
   （源文件 `asset/checklists/<叶>.md`）。
2. 逐条勾选：通过／不通过／不适用，每条附证据（命令输出行或文档条目）。
3. 不适用须说明理由（例如「非打包应用 → 包标识项不适用」）。
4. 汇总：blocking 不通过数、major 不通过数、待取证数。

## 产出

- 勾选后的清单（含证据列），blocking 不通过项优先进入
  [重构建议](../重构建议/重构建议.md)。
- 过程链：`step 评审清单 done`＋计数摘要。

## 兜底

- 清单条目与实测矛盾 → 以实测为准，把条目差异记入 `CHANGELOG.md` 待办。
- 叶无清单文件 → 视为结构缺陷，回 [知识库构建](../../../references/知识树/知识树.md) 补齐。

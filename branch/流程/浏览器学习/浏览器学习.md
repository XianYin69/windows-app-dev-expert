# 浏览器学习（横切节点）

## 触发条件

任一节点遇到不确定的 API 名、参数、枚举、版本行为、最低构建号或系统策略时，
**先取证再作答**（红线，见
[浏览器学习约束](../../../resistance/浏览器学习约束/浏览器学习约束.md)）。

## 动作

1. 派 `file_ops` 检索官方文档（learn.microsoft.com 优先），取原文页面而非搜索摘要。
2. 记录：页面短名、URL、取证时间、文档版本或适用构建号。
3. 回填出处：可确证 → 标 `[联网]` 并写入 `references/参考书目/`；
   不可确证 → 标 `[本地]`，禁止附 URL。
4. 新条目若属既有叶 → 只补细则与清单；属新领域 → 先按
   [知识树](../../../references/知识树/知识树.md) 的三条件判据决定是否成叶。
5. 回原节点继续，逻辑链记「取证前后判据变化」。

## 兜底

- 无网络授权／取页失败 3 次 → 记 `interrupt`，结论降级为 `[待取证]`＋给命令。
- 属 Qt／Web 前端 → 转派对应技能，不在本节点自答。

# 取证探查

## 动作

按叶选择探针，全部命令须可复现地写进结论：

| 探针 | 取证对象 |
|---|---|
| `os_probe.py` | 版本／构建号／架构／域／shell／已知目录 |
| `sdk_probe.py` | Windows SDK、MSVC 工具集、`signtool`／`makeappx` |
| `dotnet_probe.py` | .NET SDK／运行时／共享框架／TFM 可用性 |
| `sign_probe.py` | 文件签名状态与证书链、时间戳 |
| `msix_probe.py` | 包清单、依赖、当前进程包标识 |
| `service_probe.py` | 服务、计划任务、启动项状态 |
| `dpi_probe.py` | 逐显示器 DPI／缩放／工作区 |
| `etw_probe.py` | ETW 会话、事件日志通道可读性 |

## 产出

- 实测摘要（结论＋关键行＋命令），缺项写明「未取证」及原因。
- 过程链：探针返回码与非零原因。

## 兜底

- 权限不足（`Access Denied`）与「对象不存在」分开报告，不得合并为「无」。
- 工具链缺失 → 按 [降级策略](../../../resistance/降级策略/降级策略.md) 降层，
  并给出用户可自行执行的补取证命令。
- 涉及 HKLM／服务改动 → 停在只读取证，转 [注册表与服务安全约束](../../../resistance/注册表与服务安全约束/注册表与服务安全约束.md)。

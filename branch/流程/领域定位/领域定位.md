# 领域定位

## 动作

1. 关键词映射到九叶：`python -B scripts/classify_topic.py -q "<问题文本>"`
   （数据源 [knowledge_tree.json](../../../asset/knowledge_tree.json)）。
2. 命中多叶时按优先级排序（数字小者先判）：正确性优先于风格。
3. 未命中 → 判为范围外，走转派（见
   [薄技能依赖约束](../../../resistance/薄技能依赖约束/薄技能依赖约束.md)）。
4. 记录叶 id 与命中的探针名，供 [取证探查](../取证探查/取证探查.md) 使用。

## 产出

- 叶 id 列表（≤3 叶）＋ 每叶待用探针 ＋ 转派建议（若有）。
- 逻辑链：定位理由（为何不是另一叶）。

## 兜底

- 叶边界争议 → 两叶清单都跑，取更严的判据并在链里记冲突。
- 分类脚本不可用 → 人工按 [知识树索引](../../../references/知识树/知识树.md) 定位。

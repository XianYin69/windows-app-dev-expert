# 知识检索

## 动作

1. 取叶内细则：`asset/knowledge/<叶>.md`；取清单：`asset/checklists/<叶>.md`。
2. 机读检索：`python -B scripts/knowledge_index.py --leaf <叶id>`
   （关键词、探针、引用出处一次拿全）。
3. 判据不足或版本行为不明 → 走横切节点
   [浏览器学习](../浏览器学习/浏览器学习.md) 联网取证后再回本节点。
4. 每条拟引用结论标注来源：`[联网]`（附原始链接）或 `[本地]`（禁止附 URL）。

## 产出

- 判据集（每条含出处）＋ 缺口清单（需联网或需实测的项）。
- 逻辑链：为何采信该出处（版本、页面、构建号）。

## 兜底

- 细则与实测冲突 → 以实测为准，回写 `CHANGELOG.md` 待办，不静默改判据。
- 无网络授权 → 全部标 `[本地]`，结论降级为「待取证」，见
  [浏览器学习约束](../../../resistance/浏览器学习约束/浏览器学习约束.md)。

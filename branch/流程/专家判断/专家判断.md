# 专家判断

## 动作

1. 逐条把判据落到级别：`blocking` / `major` / `advisory`。
2. blocking 须引权威依据条文或**可复现缺陷**（命令＋期望值＋实际值）；
   风格偏好一律只作 advisory。
3. 判据顺序：正确性 → 安全与权限边界 → 契约完整（API／版本） →
   可运维性 → 性能 → 风格。
4. 语言级问题（所有权、UB、借用）转 `cpp-expert` / `c-expert` / `python-expert`，
   本节点只出 Windows 平台层结论。
5. 结论涉及目标机环境时，逐条对照 [平台假设约束](../../../resistance/平台假设约束/平台假设约束.md)。

## 产出

- 判断集：`[级别] | 判据 | 出处`，每条可独立复核。
- 逻辑链：关键取舍（为何不是另一判据）。

## 兜底

- 证据不足 → 输出「待取证」而非猜测，并给取证命令。
- 判据冲突 → 交 `constraint_arbiter` 仲裁，不私自取其一。
